# 🍽️ DineIn

**DineIn** is a simple iOS project created to explore and learn the latest **SwiftUI** features and updates for 2026, including modern state management architecture (`@Observable` / Observation framework).

## 🛠️ System Requirements

To run this project with the latest SwiftUI APIs and updates, make sure your development environment meets the following minimum specifications:

| Component | Minimum Requirement |
| :--- | :--- |
| **iOS Deployment Target** | iOS 17.0+ (Recommended iOS 18.0+) |
| **Xcode** | Xcode 15.0+ (Recommended Xcode 16.0 / Latest 2026 Xcode release) |
| **Swift Version** | Swift 5.9 / Swift 6.0 |
| **macOS** | macOS Sonoma 14.0+ or macOS Sequoia |

---

## 🚀 How to run project

1. **Clone repository ini**:
   ```bash
   git clone [https://github.com/dhikadityre/DineIn.git](https://github.com/dhikadityre/DineIn.git)
   ```
2. Open DineIn.xcodeproj in Xcode.

3. Select a Simulator:
Choose an iOS Simulator (e.g., iPhone 15 Pro or iPhone 16 Pro).

4. Run the Application:
Press CMD + R in Xcode to build & run.

## 💡 Key Features & Learnings
Implementation of @Observable macro (Observation Framework)

Modern Navigation handling (NavigationStack)

Clean Architecture using the latest SwiftUI & ViewModel patterns
